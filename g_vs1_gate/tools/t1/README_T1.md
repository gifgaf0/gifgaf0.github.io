# T1 scanner rules (G-VS1; the scanner t1_scan.py 6b86290090a8c84f1b1a0a99ec0bf697 is the frozen one of G-MSCS1)

Pattern lines only ('#' comment lines and blank lines are ignored); case-sensitive substring match. A bare numeric pattern (every character in the set 0-9 . e E + - × ^ space ⁻ ⁰¹²³⁴⁵⁶⁷⁸⁹) is a hit only if the maximal token of numeric characters containing the match equals the pattern (the contextual numeric rule); otherwise the match is logged as a formatting COLLISION, not a hit. Hits are reported by pattern INDEX only (never by the pattern's text). The gate list T1_forbidden_G_VS1.txt = the base list (11 patterns) followed by the G-VS1 stratum (20 patterns): indices 0-10 base, 11-30 stratum. The stratum file hits itself under the gate list by construction (a positive control of the scanner); lists are not scanned.
