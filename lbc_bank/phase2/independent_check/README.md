# Independent check of the Phase 2, question 1 calculation

**Plain-language summary.** A separate agent checked the question 1 results. It had not seen the work and was told not to open or run the original scripts. It used different methods, and every claim held:
- **Topological charge.** It counted the signed points where the field hits a chosen value, instead of integrating over space. The charge came out 1 for the Borromean core threaded once, 1 for the same rings pulled apart, 0 with an envelope that never vanishes, and 3 with three threading loops. These values did not depend on the field amplitude.
- **Link type.** SnapPy identifies the three ellipses as the Borromean rings (L6a4). The translated triple is the 3-component unlink.
- **Group facts.** PSL(2,7) has no quaternion subgroup; SL(2,7) has 14.
- **Super-K exponent.** The arithmetic gives 152.05.
- **Sources.** The seven literature items say what the report attributes to them.

The checker's scripts are kept here unedited. The logs were regenerated by rerunning them.

| File | Method |
|---|---|
| `fields.py` | Fields built with sympy, differentiated symbolically |
| `fast_fields.py` | Hand-coded fields and gradients; cross-validated against `fields.py` |
| `method1.py` → `method1.log` | Regular value w = (e^{iθ}, 0). Preimages lie on the z₂ zero circles and are found by 1D root finding. 5 values of θ × 2 amplitudes per configuration |
| `method2.py` → `m2_ce.log`, `m2_bf.log` | Generic regular values (both components nonzero), found by multi-start Newton in R³. 3 random w, each with ±w, × 2 amplitudes. Counts with cancelling signs occur (3 or 5 preimages summing to 1; 2 or 6 summing to 0) |
| `linking.py` → `linking.log` | Gauss linking numbers of the oriented zero loops |
| `borromean.py` → `borromean.log` | PD codes from three projections, SnapPy/spherogram identification, the checker's own Kauffman–Jones state sum |
| `groups.py` → `groups.log`, `sympy_check.py` → `sympy_check.log` | Subgroups of PSL(2,7) and SL(2,7) enumerated from scratch over F₇; sympy Sylow 2-subgroup check |

**Note on `borromean.log`.** In one projection of the translated triple, one ring has no crossings, so it drops out of the PD code. That entry shows a 2-component unlink. The other two projections, and the planes z = −0.25 and z = 0.75 that separate the three rings, settle it as the 3-component unlink.

**Requirements.** numpy, scipy and sympy. `borromean.py` also needs `snappy` and `spherogram` (SnapPy 3.3.2 was used).
